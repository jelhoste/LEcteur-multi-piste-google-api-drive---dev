Convertir des M4A en Opus (outil)

L'encodeur est figé : toutes les pistes d'un morceau doivent être converties avec exactement les mêmes réglages pour rester alignées.

Vous pouvez choisir directement le ZIP du morceau (JSON, paroles et .m4a) : les JSON et les paroles sont repris tels quels dans le ZIP de sortie, les .m4a sont convertis. Sinon, choisissez les .m4a.

Le premier lancement télécharge environ 10 Mo (encodeur), puis il reste disponible hors ligne. original.m4a devient original.opus ; les autres pistes vont dans stems/.

Composants tiers embarqués : FFmpeg (licence GPL-2.0 ou ultérieure), libopus, opusscript. Voir LICENSES.md.
